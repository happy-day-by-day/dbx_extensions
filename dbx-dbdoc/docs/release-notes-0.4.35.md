# 数据库文档 v0.4.35

- 新增多表查看：点击目录表行选择或取消，通过颜色标识已选表，右侧按目录顺序连续展示；支持全选当前搜索结果、清空选择，搜索或筛选时保留已选表，切换数据库时清空选择。
- 单表 / 多表切换使用目录标题行中的轻量文字按钮，多表内容使用完整可用宽度；各表独立搜索字段、切换字段 / 索引 / 约束、生成参考建表 SQL 和导出，外键可加入并定位引用表，较远的文档按需加载。
- 记住「紧凑」开关，再次打开文档或切换表、数据库时恢复设置，单表和多表共用。
- 索引页改为紧凑表格，每个索引一行；联合索引按字段顺序展示 ASC / DESC、表达式和前缀长度，包含字段与过滤条件分别展示为 INCLUDE 和 WHERE，保留唯一约束信息。支持本地索引搜索、复制索引名及从字段索引标记定位。
- 修复批量生成时将历史文档名称、连接默认库无条件并入数据库任务的问题。现在仅使用本次数据库目录确认的库名，避免历史中混入的表名或失效名称被当作数据库连接。
- 不再使用历史名称尝试读取数据库目录；基础会话关闭时，仅使用连接配置的默认库重试目录读取。目录部分读取成功时仅保留已确认的库，目录失败或响应缺少库名时显示原因，不创建未经确认的任务。
- 保留已有本地文档；真实数据库访问失败时仍保留上次完整缓存及成功同步时间，继续处理其他数据库。库名是否有效以目录为准，不按名称前缀或是否与表同名猜测。
- 继续提供单个通用 `.dbxp`，适用于 macOS、Windows、Linux 的 x64 / arm64，无需宿主补丁或额外运行时。安装包未签名，需在 DBX 中允许安装未签名插件；升级后关闭并重新打开数据库文档工作台。

验证：296 项前端测试通过（批量生成 25 项），Svelte 检查无错误和警告，后端竞态检查及生产构建通过。浏览器模拟宿主验证多表查看和索引交互，1280 / 900 / 720 / 390 px 下无页面横向溢出，本地浏览操作不发起 SQL 查询。Chrome 使用模拟 DBX 数据接口和包内 macOS arm64 快照后端完成 10 项批量生成检查，覆盖历史名称混入、空目录、目录失败、错误响应、分页失败和 1044 权限错误；未连接用户实际数据库。通用包六平台架构与内容校验通过，本机包内启动器的重启恢复和中断写入保护通过；Windows / Linux 尚未进行实机运行验证。详细记录见仓库 `dbx-dbdoc/docs/` 下的 `row-selection-verification-2026-11-12.json`、`index-view-verification-2026-11-12.json`、`batch-targets-verification-2026-11-12.json` 和 `package-verification-0.4.35.json`。
