# 数据库文档 0.4.26

- 修复批量生成遇到 `plugin UI storage exceeds 1048576 bytes` 失败的问题。
- 增加 Go 本地缓存后端，将文档和入口记录保存到插件专用数据目录，不再受 UI 存储每项 256 KiB / 总量 1 MiB 限制。
- 自动迁移已有 UI 存储缓存；完整写入并校验成功后才清理旧副本，迁移失败仍可查看旧文档。
- 分块传输和 SHA-256 校验，整份文件落盘后原子替换；刷新失败保留上次完整文档及成功时间。
- 迁移不会覆盖其他文档工作台刚刷新的缓存；分块读取期间版本变化会重新读取，避免混入两次同步的数据。
- 提供 macOS arm64/x64、Windows x64、Linux x64/arm64 安装包，升级后关闭并重新打开文档工作台。

候选包未签名，请选择与系统及架构一致的安装包。
