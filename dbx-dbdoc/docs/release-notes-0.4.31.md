# 数据库文档 v0.4.31

- 新增多表查看模式：在左侧目录勾选多个表，右侧按目录顺序连续展示文档，支持全选当前搜索结果和清空选择。
- 多表文档各自支持字段搜索、字段 / 索引 / 约束切换、参考建表 SQL 与导出；目录筛选保留已勾选项，外键可定位到引用表。
- 多表内容按可见区域加载，本地缓存可直接查看；切换数据库时清空多表选择，从 DBX 打开指定表时返回单表查看。
- 记住「紧凑」开关，再次打开文档、切换表或数据库时恢复上次设置，多表模式使用相同设置。
- 继续提供单个通用 `.dbxp`，适用于 macOS、Windows、Linux 的 x64 / arm64，无需宿主补丁或额外运行时。

验证：286 项前端测试、Svelte 检查与生产构建通过。浏览器模拟宿主验证多表选择、排序、独立搜索与标签页、SQL / 导出、外键定位、延迟加载、数据库切换和紧凑设置；在 1280 / 900 / 720 / 390 px 下无横向溢出，本地操作 SQL 查询为 0。详见同目录 `multi-table-verification-2026-11-12.json`；通用安装包验证见 `package-verification-0.4.31.json`。
