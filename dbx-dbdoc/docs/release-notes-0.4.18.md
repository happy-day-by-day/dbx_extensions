# 数据库文档 0.4.18

本次发布加入完整的本地文档缓存与离线浏览，并重构数据库文档切换页。

## 本地缓存与手动刷新

- 打开文档直接读取本地缓存，不自动查询数据库；仅点击「刷新」才重新读取全库结构。
- 全库同步覆盖所有表的字段、注释、索引、约束与建表 SQL，无需逐表打开，无 128 张表限制。
- 新数据先在内存中暂存，仅在整库完整成功并保存成功后整体替换正式缓存。
- 刷新失败、部分表失败或保存失败，保留上次成功的完整文档及成功同步时间；首次同步失败不保存半份文档。
- 本地缓存压缩保存，适配宿主存储限制；所有查询共用最多 4 条并发队列，避免 DBX 并发超限。
- 顶部以紧凑的「本地缓存」标识展示来源，点击可查看最后成功同步时间和刷新入口。

## 离线搜索与导出

- 直接从本地缓存搜索字段名与字段注释，保留匹配摘要、高亮、Schema 筛选和跨 Schema 同名表隔离。
- 离线支持整库及当前 Schema 的 Markdown 导出，不触发数据库请求；文档标注缓存来源、时间和缺失表清单。

## 文档切换页重构

- 左侧清晰显示连接名称、数据库类型，右侧使用紧凑数据库列表，减少重复信息。
- 展示缓存完整性、表数量与最后成功同步时间，标记当前文档，支持「有本地缓存」筛选。
- 默认选中当前或最近连接，保留搜索、名称编辑、返回和 Escape 操作。
- 适配窄窗口横向连接列表、深色主题与长名称。
- 切换页只读取本地记录，点击「刷新列表」才查询数据库列表。

## 安装与验证

下载 `.dbxp` 文件，在 DBX 插件中心开启「允许安装未签名开发包」后安装。升级后关闭并重新打开数据库文档工作台。插件不能主动建立数据库会话；首次同步或手动刷新前需在 DBX 打开目标数据库。

本地验证：236 项测试通过，Svelte 检查 0 错误、0 警告，生产构建与安装包校验通过。已验证缓存优先、断连搜索与导出、失败保留完整旧缓存及桌面 / 窄窗口 / 深色主题切换页。
