# 数据库文档 0.4.25

- 「批量更新缓存」扩展为「批量生成文档」，读取当前已建立连接的数据库目录，包含尚未缓存、未在最近文档中出现的数据库。
- 新库生成完整离线文档，已有库更新缓存；连接未建立或数据库会话未打开时跳过，不自动连接。
- 不再只保留最近 8 个文档入口，批量生成的数据库可在本地列表中继续打开。
- 目录支持分页；目录读取失败或不完整时按连接展示原因，已发现和已知数据库仍可生成。
- 可取消目录检查、完成当前库后停止后续生成；每库整库成功后才替换缓存和同步时间，失败保留旧缓存。
- 「刷新列表」仍只读取本地记录及缓存摘要，不查询数据库。

安装未签名候选包时，在 DBX 插件中心开启「允许安装未签名开发包」，升级后重新打开文档工作台。
