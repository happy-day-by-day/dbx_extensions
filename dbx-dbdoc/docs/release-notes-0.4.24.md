# 数据库文档 0.4.24

- 新增「批量更新缓存」独立弹窗，预览已连接连接下的已保存数据库与默认库。
- 开始后逐库确认数据库会话，跳过未连接或未打开的会话，不自动连接。
- 展示每库表级进度及成功、失败、跳过结果；可完成当前库后停止后续更新。
- 每个库整库同步并保存成功后才整体替换缓存、更新同步时间；失败保留旧文档，不影响其他库。
- 数据库逐个更新，查询共用最多 4 条并发预算。
- 批量结束后列表重读本地缓存状态，返回当前文档时加载更新后的缓存。
- 「刷新列表」仍只重读本地数据；批量更新不受当前搜索或缓存筛选条件影响。
- 新增 `host.connections:read` 权限，旧宿主缺少连接状态接口时提示升级。

安装未签名候选包时，在 DBX 插件中心开启「允许安装未签名开发包」，升级后重新打开文档工作台，并允许读取连接状态和所需连接的只读数据访问。
