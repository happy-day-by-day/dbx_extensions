# 数据库文档 v0.4.29

- 文档选择页支持点击「数据库」「连接名称」「最后成功同步」表头进行本地升降序排序，并显示当前排序方向。
- 名称使用自然排序（例如 db2 排在 db10 前）；同步时间首次点击按最新优先，没有成功同步记录的文档始终置后；相同值保持原有顺序。
- 搜索、缓存筛选和刷新本地列表时保留当前排序；窄窗口提供排序下拉框，可恢复默认顺序。
- 排序仅使用已加载的本地列表与缓存摘要，不查询或连接数据库，不改写原始记录和文档缓存。
- 保持一个通用 `.dbxp`，无需宿主补丁；保留快照目录配置、重启恢复、离线搜索及整库导出。

验证：284 项前端测试、Svelte 检查（0 错误 / 0 警告）、构建及包内校验通过；浏览器验证三列升降序、同值稳定排序、未知同步时间置后、筛选及刷新保持排序、键盘与窄屏操作，数据库查询为 0。验证记录见 [verification-0.4.29.json](verification-0.4.29.json)。
