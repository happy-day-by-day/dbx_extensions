# 数据库文档 v0.4.38

- 文档选择列表新增按库清除本地缓存的入口。每行右侧提供轻量图标，确认框展示数据库和连接名称；仅清除该连接、数据库、类型对应的文档及最后成功同步时间，保留普通业务库的列表记录。
- 清除操作无需连接数据库。清除当前文档时立即移除内存中的旧表结构、搜索结果和详情；需要时可点击「刷新」重新生成缓存。
- 清除采用快照原子替换，提交失败或并发修改冲突时保留已有缓存。删除标记阻止旧 UI 缓存或旧原生缓存文件在重启后重新导入；同步期间禁用清除。
- MySQL / MariaDB 自动枚举和批量生成排除 `__cdb_recycle_bin__` 及原有四个系统库。查询、返回结果和执行阶段均检查，使用完整名称匹配；相似名称的业务库正常保留，系统库所在分页不影响后续业务库读取。
- 修复系统库已无缓存但仍由历史记录显示在文档列表的问题。本地列表、当前上下文和快照恢复的入口统一应用系统库过滤，刷新列表及重启后生效，无需查询数据库。
- 继续提供单个通用 `.dbxp`，适用于 macOS、Windows、Linux 的 x64 / arm64，无需宿主补丁或额外运行时。升级后关闭并重新打开数据库文档工作台。

验证：310 项前端测试通过，Svelte 检查无错误和警告，后端竞态检查、生产构建及通用包校验通过。Chrome 使用模拟 DBX 宿主和包内 macOS arm64 快照后端，验证清除失败保留原文件、同名库隔离、当前文档清空、重启后不从旧缓存恢复，以及系统库历史记录在连续刷新和重启后保持过滤；这些本地操作没有发送数据库查询。桌面及 390 px 窄屏验证通过，未连接实际用户数据库。通用包内六平台架构和内容校验通过，本机启动器的自定义目录恢复及中断写入保护通过；Windows / Linux 未进行实机运行验证。
