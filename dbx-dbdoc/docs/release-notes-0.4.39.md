# 数据库文档 v0.4.39

- 多表文档增加独立边框、标题底色和 10–12 px 间距，表与表之间更容易辨认，当前表使用主题色标记。
- 多表区顶部新增 34 px 高的紧凑跳转栏，可通过「已选表」下拉框快速定位，支持上一张 / 下一张及当前位置计数。下拉项展示 Schema、表名和注释，跨 Schema 同名表分别定位。
- 手动滚动同步当前位置；目录搜索或 Schema 筛选不会缩减已选表的跳转列表，目录排序会同步调整跳转顺序。
- 修复跳转较远表时，途中表格延迟展开导致的定位偏移；连续跳转以最后选择为准，外键关联表加入选择后自动定位，遵循系统减少动画设置。
- 保持各表独立搜索、页签切换、建表 SQL 和导出功能，日常浏览直接读取本地缓存。
- 继续提供单个通用 `.dbxp`，适用于 macOS、Windows、Linux 的 x64 / arm64，无需宿主补丁或额外运行时。升级后关闭并重新打开数据库文档工作台。

验证：310 项前端测试通过，Svelte 检查无错误和警告，后端竞态检查、生产构建及通用包校验通过。Chrome 使用模拟 DBX 宿主和本地缓存，验证浅色 / 深色、多表间距、上一张 / 下一张边界、跨 Schema 跳转、远处表延迟加载、连续跳转、手动滚动、键盘操作、减少动画、外键跳转及四种窗口宽度；这些离线操作没有发送数据库查询，未连接实际用户数据库。通用包内六平台架构和内容校验通过，本机启动器的自定义目录恢复及中断写入保护通过；Windows / Linux 未进行实机运行验证。

详细记录见仓库 `dbx-dbdoc/docs/` 下的 `multi-navigation-verification-2026-11-12.json` 和 `package-verification-0.4.39.json`。
