# 数据库文档 v0.4.27

- 恢复纯前端通用包，同一 `.dbxp` 用于 macOS / Windows / Linux，不包含 Go 后端。
- 新增「快照目录」入口，可填写路径并通过系统选择器一次授权；重启后自动恢复本地文档。
- 完整文档以快照文件保存，避开插件 UI 存储 1 MiB 限制。旧缓存与原快照保留。
- 更换目录前复制快照；目标已有文件保留，复制失败不切换原配置。当前目录也保存在宿主，UI 存储满或偏好丢失后仍可恢复。
- 读写附带 SHA-256 校验及原子提交；整库成功才替换缓存和成功时间。目录失效、权限撤销、写入失败均提供恢复入口。
- 保留本地字段搜索、字段注释搜索、整库导出、全宽文档切换页和已连接数据库批量生成。

此版本依赖新增宿主 Host API 1.5，需先集成 `host/dbx-directory-access.patch`。
当前公开旧版 DBX 没有该接口。宿主扩展为通用目录授权及读写能力，未引入文档或数据库业务。

已通过插件检查、构建及回归测试；宿主前端检查、Rust 编译、目录核心与协议测试；
真实 Rust 目录服务重启、2.2 MB 级快照持久化、失败保留原文件、本地搜索和约 4.3 MB 整库导出联调。
原生选择器交互与 Windows / Linux 实机验收仍待进行。安装候选包未签名。
