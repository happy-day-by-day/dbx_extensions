# 数据库文档 v0.4.28

- 只需安装一个 `universal.dbxp`，无需修改或升级为补丁版 DBX。
- 同包包含 macOS、Windows、Linux 的 x64 / arm64 存储程序，由现有后端启动入口自动选择；用户不需要安装 Go、Rust 或其他运行时。
- 默认保存到插件数据目录，也可在「快照目录」填写自定义绝对路径并保存；配置持久化在插件数据目录，重启后自动恢复。
- 更换目录时先复制完整快照，再切换默认目录。已有文件、原目录和失败前的完整文档均保留。
- 保留完整快照原子提交、成功时间、离线字段与注释搜索、整库导出及批量生成。

此版本使用现有 Host API `^1.4` 和 sidecar protocol v1；不再声明 `host.directory:*`，不依赖 0.4.27 的宿主目录扩展。路径直接由用户配置，实际访问仍受操作系统文件权限限制，不能绕过系统的隐私权限或沙箱限制。候选包未签名。

验证：284 项前端测试、14 项后端测试（race detector）通过；使用未修改的原版 Host API 1.4 清单代码验证包兼容性。包内程序经 3 次进程启动、4.4 MB 快照、写入中断及目录恢复校验；浏览器联调验证离线搜索、约 4.3 MB 整库导出和失败保留原文件。Windows / Linux 已完成交叉编译及架构校验，实机运行仍待验收。
