## DBX-MCP 实际数据库

通过现有消费医疗 TEST 连接，只读查询 `tongxin_hospital` 的 INFORMATION_SCHEMA；没有查询业务行或修改数据库。

- MySQL 版本为 `5.7.44-txsql-log`，286 张基础表、5,104 个字段。
- 将当前 MySQL adapter 生成的目录 SQL 包成聚合查询，改造前返回 286 / 5,104，耗时 5,036ms；改为字段数一次分组后关联，返回数量相同，耗时 53ms。
- 当前 adapter 生成的字段、旧版兼容索引、外键 SQL，在样本 `common_operate_log` 返回 10 个字段、1 个索引、0 个外键字段，聚合查询耗时 37ms。

上述耗时是同一连接连续查询的单次观察，可能受到数据库缓存、服务器负载和网络影响；不是冷启动、p95 或端到端插件耗时承诺。
