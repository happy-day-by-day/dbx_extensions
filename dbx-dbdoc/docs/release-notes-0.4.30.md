# 数据库文档 v0.4.30

- 快照存入文件，支持手动配置存储目录，重启后自动恢复，避免整库文档受到插件 UI 存储 1 MiB 限制。整库同步全部成功后才替换缓存并更新最后成功同步时间；刷新失败保留上次完整缓存。
- 打开文档优先使用本地缓存，手动点击「刷新」才重新读取数据库。字段名、字段注释搜索与整库 Markdown 导出均可直接使用缓存。
- 支持批量生成当前已连接的数据库文档，包括尚未缓存的数据库；同步进度与失败信息集中显示。
- 文档选择页使用完整可用宽度，展示数据库、连接名称、缓存信息和最后成功同步时间；支持本地搜索、筛选，以及数据库、连接名称和同步时间排序。刷新列表无需连接数据库。
- 移除列表固定的 77–78 px 最小行高，缩小上下内边距；普通桌面行高降至 47 px，窄窗口按内容换行，长名称仍完整展示。
- 提供单个通用 `.dbxp`，包含 macOS、Windows、Linux 的 x64 / arm64 后端，基于现有 Host API 1.4，无需宿主补丁或另装运行时。

验证：284 项前端测试、后端 race 测试、Svelte 检查和生产构建通过。浏览器在 1280 / 900 / 760 / 390 px 下验证布局、搜索、排序和缓存文档切换，无横向溢出，本地操作 SQL 查询为 0。包内六个平台二进制架构与文件校验通过；macOS arm64 已验证快照写入、重启恢复和写入中断保留旧缓存，Windows / Linux 尚未进行实际运行验证。详见 [验证记录](https://github.com/happy-day-by-day/dbx_extensions/blob/v0.4.30/dbx-dbdoc/docs/verification-0.4.30.json)。

安装包未签名，需在 DBX 中允许安装未签名插件。本版不包含宿主更新时原生崩溃的修复，相关排查结论见 [崩溃调查记录](https://github.com/happy-day-by-day/dbx_extensions/blob/v0.4.30/dbx-dbdoc/docs/plugin-update-crash-2026-11-09.md)。
